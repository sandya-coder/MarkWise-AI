🧠 How This RAG System Works

This application uses a Retrieval-Augmented Generation pipeline to answer questions from uploaded documents.

📄
Document Processing PDF and TXT content is extracted.
🧠
Semantic Embeddings Text chunks are converted into embeddings.
🔎
Similarity Search Relevant chunks are retrieved using cosine similarity.
🤖
Grounded Generation Retrieved context is supplied to the language model.
🛡️
Reduced Hallucination The model is instructed to use document context only.
📚
Source Visibility Retrieved document sections are shown to the user.
